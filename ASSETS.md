# Third-party assets

Only assets that the game actually uses are committed (under `Assets/ThirdParty/<publisher>/<pack>`, each with its
`License.txt`). The complete packs are kept in `local_assets/` on the developer's machine (git-ignored) so more pieces can be
pulled in when needed. All packs below are CC0 (public domain); credit is optional.
